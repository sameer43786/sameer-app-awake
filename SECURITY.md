# Security Policy

By: Sameer Ali | Contact: sameer43786@gmail.com

## Supported version

Security fixes are currently focused on the latest published version of Sameer App Awake.

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| Earlier / modified forks | No guarantee |

## Report a vulnerability

Do not publish a security vulnerability, signing key, device identifier, or sensitive diagnostic in a public issue. Send a concise report to **sameer43786@gmail.com** with the subject `SECURITY: Sameer App Awake`.

Include the affected version, Android version, device model, reproduction steps, impact, and any proof-of-concept details that are safe to share.

## Signing material

Signing keystores and passwords must remain outside Git. The repository ignores common keystore and key formats. If a signing key is ever committed to a public repository, assume it is compromised and follow the appropriate key-rotation or signing-key upgrade process for the distribution channel in use.

## Privacy-sensitive reports

The app does not intentionally collect screen content or network data. Still, review diagnostics before sharing because package names and device/software configuration can reveal contextual information.
