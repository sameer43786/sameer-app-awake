# Changelog

All notable changes to Sameer App Awake are documented here.

## 1.0.0, 14 August 2026

- Added selectable app-specific display protection.
- Added installed-app search and multi-selection.
- Added local foreground detection through user-granted Usage Access.
- Added safety-limited screen wake-lock management.
- Added persistent notification controls and reboot recovery.
- Added live status, dark mode, adaptive icons, and copyable diagnostics.
- Added privacy safeguards with no internet, accessibility, or overlay permissions.
