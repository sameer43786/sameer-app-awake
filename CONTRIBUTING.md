## Issues and suggestions

Bug reports and feature suggestions are welcome through GitHub Issues. Before opening an issue:

1. Search existing issues.
2. Use the provided issue template.
3. Include the software version, operating system or Android version, clear reproduction steps, expected behavior, and actual behavior.
4. Remove personal data, credentials, signing files, financial records, database files, and other confidential material.

## Pull requests

This is a commercially licensed, source-available project. Unsolicited code pull requests are not accepted unless the maintainer has agreed to the contribution scope in advance. This prevents uncertainty about ownership and commercial licensing rights.

For an agreed contribution, create a focused branch, keep changes minimal, add or update tests, and describe the rationale and verification performed.
